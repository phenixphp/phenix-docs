The PhenixPHP blog will collect project updates, release context, and practical notes for developers building high-concurrency APIs with PHP.

This first entry also documents the expected frontmatter shape for future posts. Blog entries are regular Markdown files stored in `src/blog/posts`, and the documentation site discovers them automatically at build and dev time.

## What belongs here

- Release notes and migration guidance.
- Short articles about PhenixPHP features.
- Practical examples for APIs, queues, events, tasks, and asynchronous workflows.

The guide remains the canonical reference for framework behavior. Blog posts should add context, announcements, and examples without replacing the structured documentation.
